# ระบบคลิกเพื่อดำเนินคัตซีนทุก Chapter

## เป้าหมาย

ทำให้คัตซีน Chapter 2–9 รองรับการคลิกซ้ายเพื่อดำเนินบทพูดแบบเดียวกับ Chapter 1 โดยยังรองรับปุ่ม `E` และปุ่มข้ามคัตซีนตามเดิม

## พฤติกรรม

- ระหว่างคัตซีน การกด `E` หรือคลิกซ้ายหนึ่งครั้งจะดำเนินไปยังบทพูดถัดไป
- เมื่ออยู่ที่บทพูดสุดท้าย การกด `E` หรือคลิกซ้ายอีกครั้งจะดำเนินขั้นตอนถัดไปของคัตซีนหรือจบคัตซีนตามลำดับเดิม
- การคลิกปุ่ม UI เช่นปุ่มข้ามคัตซีน จะไม่ส่งผลให้บทพูดเลื่อนไปอีกหนึ่งครั้ง
- อินพุตจะทำงานเฉพาะเมื่อคัตซีนพร้อมรับการดำเนินเรื่อง เพื่อป้องกันการคลิกระหว่างเฟดหรือช่วงเปลี่ยนภาพจนลำดับคัตซีนผิด
- คัตซีนเริ่ม Chapter คัตซีนระหว่าง Chapter คัตซีนหลังบอส และคัตซีน Ending ใช้กติกาเดียวกัน

## การออกแบบ

สร้างตัวช่วยกลางสำหรับตรวจว่าเหตุการณ์อินพุตเป็นคำสั่งดำเนินคัตซีนหรือไม่ ตัวช่วยจะรับทั้งปุ่ม `E` และคลิกซ้าย พร้อมปฏิเสธคลิกที่เป็นของปุ่ม UI จากนั้นสคริปต์คัตซีน Chapter 2–9 จะเรียกตัวช่วยนี้แทนการปฏิเสธเมาส์ทั้งหมด

แต่ละคัตซีนยังคงควบคุมลำดับบทพูด การเปลี่ยนภาพ การจบฉาก และผลลัพธ์หลังคัตซีนของตนเอง ตัวช่วยกลางรับผิดชอบเฉพาะการตีความอินพุต จึงไม่เปลี่ยนเนื้อเรื่องหรือ flow เดิม

## การทดสอบ

- ยืนยันว่าคลิกซ้ายเลื่อนไปบทพูดถัดไปในคัตซีนแต่ละรูปแบบ
- ยืนยันว่าปุ่ม `E` ยังทำงาน
- ยืนยันว่าคลิกปุ่มข้ามไม่ทำให้บทพูดเลื่อนซ้ำ
- ยืนยันว่าการคลิกเมื่อคัตซีนไม่ active ไม่มีผล
- รันการทดสอบคัตซีน Chapter เดิมเพื่อป้องกัน regression
