# Chapter 3 Jatayu Feather Quest Design

## Goal

เปลี่ยนภารกิจหลักช่วงกลางของ Chapter 3 จากการกำจัดยักษ์ลาดตระเวน 2 ตัวพร้อมตอบคำถาม เป็นการตามหาและตอบคำถามเพื่อรวบรวมขนนกพญาชฎายุ 3 ชิ้น โดยยังคงการต่อสู้กับมอนสเตอร์ไว้เป็นการต่อสู้ปกติ และเริ่มคัตซีน Chapter 3 ชุดถัดไปเมื่อเก็บขนนกครบ

## Scope

- ใช้เฉพาะใน `scenes/chapter_3/chapter_3.tscn`
- ใช้รูป `res://assets/ui/icon/split/icon_wing.png`
- ใช้ Question Quiz เดิมของเกม
- ใช้ Quest Log และเครื่องหมายเป้าหมายหลายจุดเดิม
- เพิ่มขนนกเป็น item ในระบบสัมภาระเดิม
- บันทึกสัมภาระลง save slot เพื่อให้ขนนกคงอยู่หลังปิดเกมและโหลดเซฟ
- รักษาคัตซีนเปิด คัตซีนหลังภารกิจ และเควสทางออก Chapter 4 เดิม
- ไม่เปลี่ยนระบบต่อสู้ของมอนสเตอร์ใน Chapter อื่น
- ไม่ทำงาน Git

## Player Flow

1. ผู้เล่นเข้า Chapter 3 และดูคัตซีนเปิดตามเดิม
2. เมื่อคัตซีนเปิดจบ ภารกิจขนนกเริ่มทำงาน
3. ขนนก 3 ชิ้นปรากฏพร้อมกันตามจุดที่เดินถึงได้บนแผนที่
4. ขนนกแต่ละชิ้นลอยขึ้นลงอยู่กับที่ และมีเครื่องหมายเควสวงกลมกำกับ
5. เมื่อผู้เล่นเข้าใกล้ จะแสดงข้อความ `กด E เพื่อเก็บขนนก`
6. เมื่อกด E เกมเปิด Question Quiz หนึ่งคำถาม
7. ถ้าตอบถูก ขนนกชิ้นนั้นถูกเก็บ เพิ่มความคืบหน้า 1 ชิ้น และเพิ่มลงสัมภาระ 1 ชิ้น
8. ถ้าตอบผิด ขนนกชิ้นนั้นค่อย ๆ จางหาย แล้วไปเกิดใหม่ที่จุดว่างอื่นโดยไม่เพิ่มความคืบหน้า
9. เมื่อครบ 3/3 Quest Log เปลี่ยนเป็นสีเขียว ล้างเครื่องหมายขนนก และเริ่มคัตซีนถัดไปทันทีเพียงครั้งเดียว
10. เมื่อคัตซีน Chapter 3 ทั้งหมดจบ ระบบตั้งเควส `ตามรอยทศกัณฐ์` และชี้ไปทางออก Chapter 4 ตามเดิม

## Monster Behavior

- `Mob1` และ `Mob2` รับความเสียหายจากลูกธนูตามปกติ
- การยิงมอนสเตอร์ไม่เปิด Question Quiz
- มอนสเตอร์ไม่มีเครื่องหมายเควส
- การตายของมอนสเตอร์ไม่เพิ่มความคืบหน้าภารกิจขนนก
- การตายครบทั้งสองตัวไม่เริ่มคัตซีน
- ไม่กำหนด Chapter 3 controller เป็น `damage_gate` ให้มอนสเตอร์
- Shared mob behavior ยังรองรับ `damage_gate` สำหรับผู้ใช้รายอื่นได้ แต่ Chapter 3 จะไม่ใช้ hook นี้

## Feather Scene

เพิ่ม Scene ขนนกที่ใช้ซ้ำได้ภายใน Chapter 3 ประกอบด้วย:

- `Area2D` เป็น root
- `Sprite2D` ใช้ `icon_wing.png`
- `CollisionShape2D` เป็นระยะตรวจผู้เล่น
- `Label` แสดงข้อความกด E
- script ดูแลสถานะผู้เล่นใกล้ การรับ input และ animation

Feather scene ส่ง signal ไปยัง Chapter 3 controller เมื่อผู้เล่นขอเก็บ โดยไม่เปิดคำถามหรือนับคะแนนเอง เพื่อให้ controller เป็นเจ้าของ state กลางเพียงจุดเดียว

### Bob Animation

- ใช้ Tween แบบวนซ้ำ
- ขยับแกน Y ขึ้นและลงเล็กน้อย
- แต่ละชิ้นใช้ delay หรือ phase ต่างกันเล็กน้อยเพื่อไม่ให้ลอยพร้อมกันทั้งหมด
- ตำแหน่งฐานต้องไม่เปลี่ยนหลัง animation หลายรอบ

### Interaction

- ตรวจเฉพาะ `CharacterBody2D` ชื่อ `Player`
- รองรับปุ่ม E เป็นหลัก
- ระหว่าง Question Quiz เปิด ขนนกชิ้นอื่นไม่สามารถเริ่ม interaction ซ้อน
- prompt หายเมื่อผู้เล่นออกจากพื้นที่ เมื่อขนนกกำลังเฟด หรือเมื่อขนนกถูกเก็บ

## Spawn Model

- กำหนด spawn points ที่ตรวจแล้วว่าอยู่บนพื้นที่เดินได้ประมาณ 6 จุดใน Chapter 3
- เมื่อเริ่มภารกิจ สุ่มเลือก 3 จุดที่ไม่ซ้ำกัน
- มีขนนก active พร้อมกันสูงสุด 3 ชิ้น
- เมื่อตอบผิด ขนนกเลือกจุดใหม่จากจุดที่:
  - ไม่ใช่จุดเดิม
  - ไม่มีขนนกชิ้นอื่นใช้อยู่
- ถ้าไม่มีจุดอื่นว่างจริง ให้ใช้จุดว่างใดก็ได้โดยยังห้ามซ้อนกับขนนกอื่น
- ใช้ `RandomNumberGenerator` ของ Chapter 3 controller เพื่อรวมการสุ่มไว้จุดเดียวและทำให้ทดสอบได้

## Question Data

ใช้คำถามเดิมสองข้อ:

1. `คำใดอยู่ในมาตราตัวสะกดแม่กง`
   - `ลิง`
   - `ดาว`
   - `เมฆ`
   - คำตอบถูก: index 0
2. `คำว่า “วิ่ง” เป็นคำชนิดใด`
   - `คำนาม`
   - `คำกริยา`
   - `คำวิเศษณ์`
   - คำตอบถูก: index 1

ทุกครั้งที่เริ่ม interaction จะสุ่มหนึ่งคำถามจากสองข้อ อนุญาตให้คำถามซ้ำระหว่างขนนกคนละชิ้นหรือการลองใหม่หลังตอบผิด

## Quest State

Chapter 3 controller เก็บ state:

- ภารกิจเริ่มแล้วหรือยัง
- จำนวนขนนกที่เก็บได้ 0–3
- ขนนก active และ spawn point ที่แต่ละชิ้นใช้อยู่
- ขนนกชิ้นที่กำลังรอผลคำถาม
- Question Quiz เปิดอยู่หรือไม่
- คัตซีนถัดไปเริ่มแล้วหรือยัง

ข้อความ Quest Log:

- ชื่อ: `รวบรวมขนนกพญาชฎายุ`
- รายละเอียด: `ตามหารวบรวมขนนกพญาชฎายุที่ตกหล่นให้ครบ 3 ชิ้น 0/3`
- ตัวเลขท้ายเปลี่ยนเป็น `1/3`, `2/3`, และ `3/3`

Quest targets เป็นขนนก active ทั้งหมด จึงแสดงเครื่องหมายวงกลมเหนือขนนกพร้อมกันและปรับใหม่เมื่อตอบผิดจนขนนกย้ายตำแหน่ง

## Inventory and Persistence

เพิ่ม item catalog ใหม่ในระบบสัมภาระ:

- id: `jatayu_feather`
- ชื่อ: `ขนนกพญาชฎายุ`
- icon: `res://assets/ui/icon/split/icon_wing.png`

เมื่อตอบคำถามถูก:

1. เพิ่ม `jatayu_feather` ลง `Inv` จำนวน 1 ชิ้น
2. แสดงจำนวนรวมในหน้าสัมภาระ เช่น `ขนนกพญาชฎายุ x1`
3. เพิ่มได้จากภารกิจนี้สูงสุด 3 ชิ้น โดยขนนกหนึ่ง node ให้รางวัลได้เพียงครั้งเดียว
4. การเปลี่ยน Chapter ไม่ลบขนนก
5. ถ้ายังไม่มีระบบใน Chapter ถัดไปที่ใช้ขนนก จำนวนขนนกต้องคงเดิม

ระบบ save slot ต้องบันทึก dictionary ของสัมภาระทั้งหมด และคืนค่ากลับเข้า `Inv` ตอน load โดย:

- รองรับ save เก่าที่ไม่มีข้อมูลสัมภาระ ด้วยการใช้ค่าเริ่มต้นเดิม
- ทำสำเนา dictionary ตอน save/load เพื่อไม่แชร์ reference กับข้อมูล JSON
- refresh หน้าสัมภาระหรือส่ง `changed` หลัง restore
- ไม่เพิ่มขนนกซ้ำจากการ load

ความคืบหน้าภารกิจ Chapter 3 ใช้จำนวนขนนกที่เก็บในรอบภารกิจเป็นตัวควบคุมคัตซีน และตรวจจำนวนใน `Inv` เพื่อป้องกันการให้รางวัลซ้ำเมื่อ scene ถูกโหลดใหม่ระหว่างภารกิจ

## Ending Inventory Reset

เมื่อผู้เล่นเล่นเนื้อเรื่องจนถึง Ending และกดปุ่มเพื่อเริ่มเรื่องใหม่:

1. ล้าง item ทั้งหมดออกจาก `Inv` รวมถึง `jatayu_feather`
2. ตั้ง `potion` หรือ `ยารักษา` กลับเป็นค่าเริ่มต้น 3 ขวดเสมอ
3. ส่งสัญญาณ `changed` เพื่อให้ UI อัปเดต
4. จากนั้นจึงเปลี่ยนฉากกลับไปเริ่ม Chapter 1 ตาม flow เดิม

การเข้าสู่หน้า Ending เพียงอย่างเดียวยังไม่ล้างของ เพื่อป้องกันข้อมูลหายก่อนผู้เล่นยืนยันเริ่มเรื่องใหม่ จุดรีเซ็ตมีเพียงตอนกดออกจาก Ending ไปเริ่มรอบใหม่

## Correct Answer

1. ปิด Question Quiz
2. ล็อก interaction ของขนนกเป้าหมาย
3. เล่น fade-out
4. เพิ่ม `jatayu_feather` ลงสัมภาระ 1 ชิ้น
5. เพิ่มจำนวนที่เก็บได้
6. นำขนนกออกจาก active targets
7. อัปเดต Quest Log และ markers
8. ถ้ายังไม่ครบ ให้ขนนกชิ้นที่เก็บแล้วคงถูกซ่อน
9. ถ้าครบ 3/3:
   - ตั้ง Quest Log เป็น completed สีเขียว
   - ล้าง targets
   - เริ่ม post-battle cutscene หลัง fade เสร็จ

## Wrong Answer

1. ปิด Question Quiz
2. ล็อก interaction ของขนนกเป้าหมาย
3. เล่น fade-out แบบค่อย ๆ หาย
4. เลือก spawn point ใหม่
5. ย้ายขนนกไปจุดใหม่
6. คืน alpha และเริ่ม bob animation ใหม่
7. เปิด interaction อีกครั้ง
8. จำนวนที่เก็บและ Quest Log ไม่เปลี่ยน
9. อัปเดต Quest targets เพื่อให้ marker ตามตำแหน่งใหม่

## Cutscene Transition

- การตายของมอนสเตอร์ไม่เรียก post-battle cutscene อีกต่อไป
- post-battle cutscene เริ่มจาก completion handler ของภารกิจขนนกเท่านั้น
- guard เดิมหรือ guard เทียบเท่าป้องกันการเริ่มคัตซีนซ้ำ
- หลังคัตซีนสุดท้าย callback `finish_chapter_3_story()` ยัง:
  - แสดงหนุมาน
  - ตั้งเควสทางออก Chapter 4

## Scene Exit and Cleanup

- เมื่อออกจาก Chapter 3 ให้ Quest Log ล้าง targets ตามเดิม
- ถ้าออกฉากระหว่าง Question Quiz ต้องไม่เหลือ pending feather reference ที่ทำให้ error
- Tween ของขนนกต้องหยุดอย่างปลอดภัยเมื่อ node ออกจาก tree
- signal จากขนนกที่ถูกซ่อนหรือกำลังเฟดต้องไม่ทำงานซ้ำ

## Verification

### Runtime

- มอนสเตอร์ทั้งสองรับความเสียหายและตายได้โดยไม่เปิดคำถาม
- การฆ่ามอนสเตอร์ทั้งสองไม่เริ่มคัตซีน
- เริ่มเควสแล้วมีขนนก active 3 ชิ้นและ Quest target 3 จุด
- prompt แสดงเมื่อเข้าใกล้และกด E เปิดคำถาม
- คำถามและตัวเลือกทั้งสองชุดถูกต้อง
- ตอบผิดไม่เพิ่ม progress ขนนกจางหายและย้ายไปจุดใหม่ที่ไม่ซ้อน
- ตอบถูกเพิ่ม progress ครั้งละหนึ่งและนำขนนกชิ้นนั้นออก
- ตอบถูกทีละชิ้นแล้วสัมภาระแสดงขนนกเป็น x1, x2 และ x3
- progress แสดง 0/3 ถึง 3/3 ถูกต้อง
- ครบ 3/3 ข้อความเป็นสีเขียวและเริ่มคัตซีนหนึ่งครั้ง
- จบคัตซีนทั้งหมดแล้วตั้งเควสทางออก Chapter 4
- เปลี่ยน Chapter แล้วขนนกยังอยู่ในสัมภาระ
- save แล้วปิดเกม จากนั้น load กลับมา ขนนกและ item อื่นมีจำนวนเดิม
- load save เก่าที่ไม่มีข้อมูลสัมภาระได้โดยไม่ error
- เมื่อถึง Ending ของยังไม่ถูกล้างจนกดเริ่มเรื่องใหม่
- หลังออกจาก Ending ไปเริ่มรอบใหม่ เหลือเฉพาะยารักษา 3 ขวด

### Regression

- Quest Log แบบเป้าหมายเดียวและหลายเป้าหมายยังทำงาน
