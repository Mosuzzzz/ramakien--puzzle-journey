## การออกแบบ

### Asset

คัดลอกไฟล์ต้นฉบับ `/Users/siwakornbundi/Downloads/Deer.mp3` ไปไว้ในโปรเจกต์เป็น `assets/audio/sfx/deer_run.mp3` เพื่อให้ Godot import และรวมไฟล์ใน Web export/itch.io ได้ตามระบบ `res://`

ตั้งค่า stream ให้วนซ้ำ เพราะไฟล์มีความยาวประมาณ 8.1 วินาที แต่ระยะเวลาวิ่งในเกมอาจยาวกว่านั้น

### แหล่งกำเนิดเสียง

เพิ่ม `AudioStreamPlayer2D` ชื่อ `RunAudio` เป็น child ของ `GoldenDeer` ทำให้เสียงติดตามตำแหน่งกวางโดยไม่ต้องให้สคริปต์ Chapter 2 ทั้งสองฉากคอยอัปเดตตำแหน่งเสียง

`RunAudio` ใช้ bus `SFX` ที่มีอยู่ใน `default_bus_layout.tres`, ใช้ `max_distance = 900` px และ attenuation เริ่มต้นของ Godot เพื่อให้เสียงเบาลงตามระยะ ไม่ดังเท่ากันทั่วแผนที่ Chapter 2

### วงจรเริ่มและหยุด

สคริปต์ `golden_deer.gd` เป็นเจ้าของวงจรเสียง:

- `_play("run")`: เริ่ม `RunAudio` หากยังไม่เล่น
- `_play("idle")`: หยุด `RunAudio`
- `_die()`: หยุดเสียงก่อนซ่อนและหยุด physics
- เมื่อกวางถึงเป้าหมายแล้ว `queue_free()`: หยุดเสียงผ่าน `_exit_tree()` เพื่อป้องกันเสียงค้าง
- ฉากไล่ล่าที่เรียก `_golden_deer.call("_play", "run")` จะได้เสียงอัตโนมัติจาก API เดิม

ไม่เริ่มเสียงซ้ำทุก physics frame; ตรวจสถานะ `playing` ก่อนเรียก `play()` เพื่อให้ loop ต่อเนื่องและไม่กระโดดกลับต้นไฟล์

## ทางเลือกที่พิจารณา

1. **AudioStreamPlayer2D ภายใน GoldenDeer — เลือกใช้:** ผูก lifecycle และตำแหน่งเสียงกับตัวกวางโดยตรง ใช้ได้ทั้งสองฉากโดยไม่ซ้ำโค้ด
2. **ควบคุมจากสคริปต์ Chapter 2:** ทำงานได้ แต่ต้องเพิ่ม logic เริ่ม/หยุดซ้ำใน `chapter_2.gd` และ `chapter_2_second.gd` และเสี่ยงเสียงค้างเมื่อ path จบต่างกัน
3. **เพิ่ม loop ใน AudioManager กลาง:** เหมาะกับเสียงร่วมหลาย actor แต่ไม่เหมาะกับเสียง 2D ของกวางเพียงตัวเดียวและเพิ่ม state owner ที่ไม่จำเป็น

## การทดสอบ

- ตรวจว่า packed scene GoldenDeer มี `RunAudio` ชนิด `AudioStreamPlayer2D`
- ตรวจว่า stream มาจาก `res://assets/audio/sfx/deer_run.mp3` และเปิด loop
- เรียก `_play("run")` แล้วตรวจว่าเสียงเริ่มเล่น
- เรียก `_play("run")` ซ้ำแล้วตรวจว่า playback ไม่เริ่มใหม่
- เรียก `_play("idle")` แล้วตรวจว่าเสียงหยุด
- เรียก `_die()` และ `_exit_tree()` แล้วตรวจว่าเสียงหยุด
- โหลด `chapter_2.tscn` และ `chapter_2_second.tscn` เพื่อยืนยันว่ากวางทั้งสองฉากใช้ packed scene เดียวกันและ asset ไม่มี path error
- รัน Godot แบบ headless เพื่อยืนยันว่า asset import และ scripts parse ได้
