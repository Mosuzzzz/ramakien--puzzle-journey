# Chapter 6 Jar Answer Feedback Design

## Scope

ปรับเฉพาะการแสดงผลหลังเลือกคำตอบในหน้าค้นหาโหลของห้องขวา Chapter 6
โดยไม่เปลี่ยนคำถาม ตำแหน่งโหล รหัสที่พบ หรือสถานะของโหลที่ค้นแล้ว

## Wrong Answer

1. ปิดการกดปุ่มคำตอบ ปุ่มยกเลิก และปุ่มลัดชั่วคราว
2. ปุ่มคำตอบที่ผู้เล่นเลือกกระพริบสลับระหว่างสีแดงกับสีปกติเป็นเวลา 1 วินาที
3. เมื่อครบเวลา ให้คืนสีปุ่มเป็นปกติ
4. สับตำแหน่งคำตอบทั้ง 3 ตัวเลือก โดยผลลัพธ์ต้องต่างจากลำดับก่อนหน้า
5. เปิดให้ผู้เล่นตอบคำถามเดิมใหม่ได้

## Correct Answer

1. ปิดการกดปุ่มคำตอบ ปุ่มยกเลิก และปุ่มลัดชั่วคราว
2. ปุ่มคำตอบที่ถูกต้องแสดงสีเขียวค้างเป็นเวลา 1 วินาที
3. เมื่อครบเวลา ให้ซ่อนแผงคำถามและแสดงภาพด้านในโหลตามปกติ
4. ส่งสถานะว่าโหลนี้ถูกค้นแล้วเพียงครั้งเดียว
5. หลังเปิดโหล ผู้เล่นกด `E`, `Esc` หรือปุ่มยกเลิกเพื่อกลับเข้าห้องได้ตามระบบเดิม

## Already Searched Jars

โหลที่ค้นสำเร็จแล้วจะเปิดภาพด้านในทันทีเมื่อค้นซ้ำ โดยไม่แสดงคำถามและไม่เล่น
เอฟเฟกต์ตอบถูกอีกครั้ง

## Error and Input Handling

- ระหว่างเอฟเฟกต์ 1 วินาที ผู้เล่นไม่สามารถเลือกคำตอบซ้ำหรือปิดหน้าต่างได้
- หลังตอบผิดต้องไม่มีปุ่มใดค้างเป็นสีแดง
- หลังตอบถูกต้องไม่ส่งสัญญาณค้นสำเร็จซ้ำ

## Verification

เพิ่มการทดสอบ runtime เพื่อยืนยันว่า:

- เฉพาะปุ่มที่ตอบผิดเท่านั้นที่กระพริบแดง
- สีแดงมีทั้งช่วงแสดงและช่วงดับภายในเวลา 1 วินาที
- หลังครบเวลา คำตอบถูกสับและผู้เล่นตอบใหม่ได้
- ปุ่มที่ตอบถูกเป็นสีเขียวตลอดช่วงตอบรับ 1 วินาที
- ภาพด้านในโหลยังไม่ถูกเปิดก่อนครบเวลา และเปิดหลังครบเวลา
- พฤติกรรมเปิดโหลที่ค้นแล้วและการปิดหน้าต่างยังทำงานเหมือนเดิม
