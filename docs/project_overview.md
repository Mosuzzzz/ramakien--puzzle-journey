# Project Overview

## Project Overview
This project is a 2D educational adventure game built in Godot, inspired by the Ramakien. The player explores story-based stages, solves simple knowledge puzzles, and fights or avoids Thai-style giant mobs to progress through the story .

The game is designed for students in grades 2–6, so it keeps controls simple, puzzles easy, and visuals friendly. The goal is to make learning feel like an adventure rather than a test .

## Project Goal
The main goal is to create a fun and educational game where players use knowledge to unlock doors, find passwords, and clear challenges. The story should follow Ramakien events while staying understandable for young players .

## Core Gameplay
Players will:
- Move through 2D scenes.
- Talk to NPCs and collect clues.
- Solve puzzles using observation, matching, and basic knowledge.
- Defeat or bypass mobs styled like Thai yak soldiers.
- Reach the end of each chapter and continue the journey .

## Story Direction
The game starts with the hero’s mission and continues through chapters such as travel, forest exploration, conflict, infiltration, and rescue. Important story beats can include the search for Sita, the journey to Lanka, and battle-focused chapters like ศึกไมยราพ .

## Learning Focus
The educational side of the game should help students practice:
- Reading and comprehension.
- Counting and simple logic.
- Pattern recognition.
- Problem-solving.
- Memory and attention.

## Style and Tone
The game should feel like a friendly mythological adventure with bright visuals, simple Thai-inspired giant enemies, and short dialogue. Combat should stay light and non-violent enough for younger students .

## Scope
A good first version should include:
- 1 playable chapter.
- 3–5 puzzles.
- 1 boss or mini-boss.
- 1–2 mob types.
- A clear win condition.
- A hint system.
