# Chapter 3 Patrol Quest Design

## เป้าหมาย

เพิ่มลำดับเควสให้ Chapter 3 เชื่อมระหว่างคัตซีนเปิดฉาก การกำจัดยักษ์ลาดตระเวน 2 ตัว คัตซีนหลังการต่อสู้ และทางออกไป Chapter 4 โดยใช้หน้าต่าง Quest Log และรูปแบบเครื่องหมายเป้าหมายที่มีอยู่แล้ว

## ขอบเขต

- แก้เฉพาะระบบเควสและลำดับเหตุการณ์ของ Chapter 3
- ขยาย Quest Log ให้แสดงเครื่องหมายเป้าหมายหลายจุดพร้อมกันได้ โดยต้องรักษาการทำงานแบบเป้าหมายเดียวของด่านเดิม
- ไม่ล็อกทางออก Chapter 4
- ไม่แก้พฤติกรรมของ Chapter อื่น
- ไม่ทำคำสั่ง Git

## ลำดับสถานะเควส

### 1. ระหว่างคัตซีนเปิด Chapter 3

- ยังไม่แสดงเควสกำจัดยักษ์
- ยังไม่แสดงเครื่องหมายเหนือมอนสเตอร์
- ผู้เล่นยังถูกควบคุมด้วยระบบคัตซีนเดิม

### 2. หลังคัตซีนเปิดจบ

- Chapter 3 เริ่มเควส `กวาดล้างยักษ์ลาดตระเวน`
- Quest Log แสดงรายละเอียด `กำจัดยักษ์ลาดตระเวนในป่าทั้งหมด 0/2`
- แสดงเครื่องหมายวงกลมเหนือ `Mob1` และ `Mob2` พร้อมกัน
- ตำแหน่งเครื่องหมายต้องติดตามตำแหน่งปัจจุบันของมอนสเตอร์ ไม่ใช่ตำแหน่งเริ่มต้นแบบคงที่

### 3. หลังยักษ์ตัวแรกถูกกำจัด

- อัปเดตความคืบหน้าเป็น `กำจัดยักษ์ลาดตระเวนในป่าทั้งหมด 1/2`
- นำเครื่องหมายของตัวที่ถูกกำจัดออก
- เครื่องหมายของมอนสเตอร์ที่เหลือยังแสดงและติดตามตำแหน่งต่อไป

### 4. หลังยักษ์ครบสองตัวถูกกำจัด

- อัปเดตความคืบหน้าเป็น `กำจัดยักษ์ลาดตระเวนในป่าทั้งหมด 2/2`
- เปลี่ยนข้อความเควสและรายละเอียดใน Quest Log เป็นสีเขียวเพื่อแสดงว่าสำเร็จ
- ล้างเครื่องหมายเหนือมอนสเตอร์ทั้งหมด
- เริ่มคัตซีนหลังการต่อสู้ตามลำดับเดิมของ Chapter 3

### 5. หลังคัตซีน Chapter 3 จบทั้งหมด

- คืนสีข้อความ Quest Log เป็นสีปกติ
- เปลี่ยนเควสเป็น `ตามรอยทศกัณฐ์`
- แสดงรายละเอียด `เดินทางออกจากป่าเพื่อตามหานางสีดา`
- แสดงเครื่องหมายเป้าหมายที่ `Chapter4Portal`
- หนุมานยังถูกเปิดเผยตามระบบเดิม
- ทางออก Chapter 4 ยังคงใช้งานตามพฤติกรรมเดิม

## การออกแบบ Quest Log

Quest Log ปัจจุบันรองรับ `target_position` เพียงตำแหน่งเดียว จึงเพิ่ม API สำหรับรายการเป้าหมายหลาย Node โดยไม่ทำลาย API เดิม

- `set_targets(nodes)` รับรายการ Node2D ที่ยังมีชีวิต
- Quest Log สร้างเครื่องหมายจากรูปแบบเดิมหนึ่งอันต่อหนึ่งเป้าหมาย
- ทุกเฟรมคำนวณตำแหน่งหน้าจอจาก `global_position` ของแต่ละเป้าหมาย
- หากเป้าหมายออกจาก scene tree เครื่องหมายของเป้าหมายนั้นจะถูกนำออก
- `set_quest(..., target)` และ `target_position` แบบเดิมยังทำงานสำหรับ Chapter อื่นและเป้าหมายทางออก
- การตั้งเป้าหมายเดี่ยวต้องล้างรายการหลายเป้าหมาย และการตั้งหลายเป้าหมายต้องปิดเป้าหมายเดี่ยว เพื่อไม่ให้เครื่องหมายซ้อนกัน
- เพิ่มสถานะ completed สำหรับเปลี่ยนสีชื่อและรายละเอียดเป็นสีเขียว และสามารถคืนค่าสีเดิมเมื่อเริ่มเควสถัดไป

## การเชื่อมคัตซีน

- เมื่อคัตซีนเปิด Chapter 3 จบ ให้เรียกเมธอดของ Chapter 3 เพื่อเริ่มเควสกำจัดยักษ์ก่อนลบโหนดคัตซีน
- Chapter 3 เป็นเจ้าของตัวนับจำนวนมอนสเตอร์ที่ถูกกำจัดและการเปลี่ยนสถานะเควส
- ใช้สัญญาณ `tree_exited` ของ `Mob1` และ `Mob2` ที่มีอยู่แล้ว เพื่อตรวจจำนวนตัวที่เหลือ
- เมื่อคัตซีนหลังการต่อสู้และคัตซีนสุดท้ายจบ ให้เรียก Chapter 3 เพื่อเปลี่ยนเป็นเควสทางออก

## การจัดการกรณีพิเศษ

- หากมอนสเตอร์ถูกลบก่อนคัตซีนเปิดจบ สถานะเมื่อเริ่มเควสต้องคำนวณจากมอนสเตอร์ที่เหลือจริง
- การเรียกเริ่มเควสหรือเริ่มคัตซีนซ้ำต้องไม่สร้างเครื่องหมายซ้ำและไม่เล่นคัตซีนซ้ำ
- เมื่อออกจาก Chapter 3 ให้ล้างเป้าหมายหลายจุดที่อ้างถึงมอนสเตอร์ของฉาก เพื่อไม่ให้มี reference หรือเครื่องหมายค้างใน Chapter ถัดไป
- การเปิดและปิดหน้า Quest Log ต้องไม่ทำให้สถานะหรือจำนวนเครื่องหมายเปลี่ยน

## การทดสอบ

- ทดสอบว่าหลังคัตซีนแรก เควสเริ่มที่ `0/2` และมีเป้าหมาย 2 ตัว
- ทดสอบว่ากำจัดตัวใดตัวหนึ่งแล้วเป็น `1/2` และเหลือเป้าหมาย 1 ตัว
- ทดสอบว่ากำจัดครบแล้วเป็น `2/2`, สถานะ completed เป็นสีเขียว และคัตซีนหลังการต่อสู้เริ่มครั้งเดียว
- ทดสอบว่าหลังคัตซีนทั้งหมด เควสเปลี่ยนเป็นการตามรอยทศกัณฐ์และชี้ไป `Chapter4Portal`
- ทดสอบความเข้ากันได้ของ Quest Log แบบเป้าหมายเดียว เพื่อไม่ให้ Chapter อื่นเสีย
