# Chapter 6 Code Digit Shuffle Design

## Scope

ปรับเฉพาะลำดับปุ่มตัวเลขในหน้าป้อนรหัสของห้องขวา Chapter 6 เพื่อไม่ให้ตัวเลือก
แสดงเป็นลำดับเฉลย `2, 7, 3` ตั้งแต่เริ่ม โดยไม่เปลี่ยนรหัสที่ถูกต้องหรือ flow การรับ
ชิ้นส่วนกุญแจ

## Button Order

1. ทุกครั้งที่เปิดหน้าป้อนรหัส ระบบสร้างลำดับใหม่จากตัวเลข `2`, `7`, `3`
2. สุ่มลำดับหนึ่งครั้งและรับประกันว่าลำดับที่แสดงไม่ใช่ `2, 7, 3`
3. ลำดับปุ่มคงเดิมตลอดรอบที่ modal เปิดอยู่ รวมถึงหลังล้างรหัสและหลังใส่รหัสผิด
4. เมื่อปิดแล้วเปิด modal ใหม่ ระบบสุ่มลำดับใหม่ได้

## Discovered Digits

- ปุ่มแต่ละตำแหน่งแสดงตัวเลขเมื่อผู้เล่นค้นพบตัวเลขนั้นแล้ว
- ตัวเลขที่ยังไม่ค้นพบแสดง `?` และกดไม่ได้
- การสลับตำแหน่งต้องไม่ทำให้สถานะค้นพบของตัวเลขหนึ่งไปติดกับตัวเลขอื่น

## Input and Solution

- เมื่อกดปุ่ม ระบบเพิ่มค่าของตัวเลขที่แสดงบนปุ่มนั้น ไม่ใช้ตำแหน่งของปุ่มเป็นค่า
- ผู้เล่นสามารถกดตัวเลขเดิมซ้ำได้
- เฉลยที่ถูกต้องยังเป็น `273`
- การล้างรหัส การแสดงสีแดงเมื่อผิด และสีเขียวเมื่อถูกทำงานเหมือนเดิม

## Verification

เพิ่ม runtime assertions เพื่อยืนยันว่า:

- เมื่อค้นพบครบ ปุ่มไม่แสดงลำดับ `2, 7, 3`
- ปุ่มยังประกอบด้วยตัวเลข `2`, `7`, `3` ครบโดยไม่มีค่าซ้ำหรือหาย
- กดตามค่าที่แสดงสามารถสร้างรหัส `273` ได้ไม่ว่าปุ่มอยู่ตำแหน่งใด
- ปุ่มตัวเลขที่ยังไม่ค้นพบแสดง `?` และปิดการกดถูกต้องหลังสลับตำแหน่ง
- การล้างรหัสและการตอบผิดไม่เปลี่ยนลำดับปุ่มภายใน modal รอบเดียวกัน
